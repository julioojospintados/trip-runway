# trip-runway

Travel Budget Yield App — incrocia il costo del volo con il costo della vita a destinazione per calcolare i giorni massimi di permanenza sostenibili con un budget fisso. Vedi [project-brief.md](project-brief.md) per i dettagli, [CLAUDE.md](CLAUDE.md) per il framework decisionale, e [todo.md](todo.md) (locale, non versionato) per lo stato di avanzamento.

> Nome del progetto ancora in draft — vedi la nota in `project-brief.md`.
